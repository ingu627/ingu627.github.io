"Fast Hoeffding Drift Detection Method for Evolving Data Streams" 논문을 공부하고 핵심 내용을 정리한 리뷰다.

- **논문 링크**: [https://link.springer.com/chapter/10.1007/978-3-319-46227-1_7](https://link.springer.com/chapter/10.1007/978-3-319-46227-1_7)
- **핵심 문제 (Core Bottleneck)**: 고속 데이터 스트림 환경에서 기저 분포의 변화(concept drift)를 감지하는 기존 윈도우 기반 기법들은 두 개 이상의 서브 윈도우 유지나 가변 분할 검정으로 인해 메모리 사용량과 탐지 지연(detection delay)이 증가하는 한계가 있었다.
- **핵심 해결책 (Key Insight)**: 단 하나의 고정 크기 슬라이딩 윈도우($n$)를 유지하며 과거 관측된 최대 예측 확률($p_{max}^1$)과 현재 윈도우의 정확도($p_t^1$)를 호에프딩 부등식(Hoeffding's inequality) 한계치($\epsilon_d$)로 비교하여, 극소의 메모리와 $O(1)$ 연산 복잡도만으로 신속하고 정확하게 드리프트를 탐지한다.

## 1. Introduction

지속적으로 변화하는 스트림 환경에서 머신러닝 모델을 실시간으로 학습하고 적응시키는 작업은 매우 까다로운 도전 과제다.

스트림 처리의 어려움은 유입 데이터의 속도와 방대한 크기뿐만 아니라, 시간이 지남에 따라 데이터의 기저 통계 분포가 변하는 컨셉 드리프트(concept drift)가 발생할 때 더욱 두드러진다. 이러한 분포 변화는 사전에 학습된 분류 모델의 예측 성능을 점진적 혹은 급격하게 저하시킨다. 따라서 적응형(adaptive) 학습 시스템은 드리프트 감지 기법(drift detection method)을 도입하여 분포 변화를 조기에 감지하고 적절한 대응책을 취해야 한다.

- **재학습(Retraining)**: 드리프트가 검출되는 시점에 분류 모델을 즉시 업데이트하거나 새로운 데이터로 재학습을 진행한다.
- **앙상블 적응(Ensemble Adaptation)**: 대안으로 앙상블 학습 알고리즘을 활용하여 모델의 가중치를 동적으로 조절함으로써 정확도를 유지한다.

드리프트 감지기를 평가할 때는 오경보율과 탐지 지연이 핵심 기준이 된다. 높은 위양성(FP, False Positive) 비율을 가진 감지기는 불필요한 모델 재학습을 유발하여 시스템 자원을 낭비한다. 반대로 높은 위음성(FN, False Negative) 비율을 가진 감지기는 실제 드리프트를 놓쳐 분류 정확도의 심각한 감쇠(decay)를 방치하게 된다. 나아가 탐지 지연(detection delay)을 최소화하면서 정확한 드리프트 발생 지점을 추정하는 것은 최신 데이터를 온전히 활용하고 드리프트 양상을 규명하는 데 필수적이다.

결국 감지 지연과 오경보를 모두 낮추는 경량 탐지기가 스트림 학습의 핵심이다.

Fast Hoeffding Drift Detection Method (FHDDM)은 고정 슬라이딩 윈도우(sliding window)와 호에프딩 부등식(Hoeffding's inequality)을 결합하여 정답 예측 확률의 최댓값과 현재 확률을 통계적으로 비교한다. FHDDM은 기존 SOTA 기법들과 비교하여 더 적은 탐지 지연(less detection delay)과 낮은 FP 및 FN 비율을 동시에 달성한다.

## 2. Related Works 

기존의 컨셉 드리프트 감지 기법(concept drift detector)은 통계적 접근 방식에 따라 크게 3가지 그룹으로 분류할 수 있다.

- **(1) Sequential Analysis based Methods**: 순차적으로 모델의 예측 결과를 평가하며, 사전 정의된 임계치에 도달할 때 드리프트 알람(alarm)을 발생시킨다. Cumulative Sum (CUSUM), Geometric Moving Average (GMA) 등이 대표적이다.
- **(2) Statistical based Methods**: 예측 결과의 평균(mean)과 표준 편차(standard deviation)를 모니터링하여 분포의 통계적 파라미터 변화를 기반으로 스트림 드리프트를 검출한다. Drift Detection Method (DDM), Early Drift Detection Method (EDDM), Exponentially Weighted Moving Average (EWMA) 등이 여기에 속한다.
- **(3) Windows based Methods**: 윈도우를 활용하여 과거 정보와 최근 정보의 통계량을 비교하고, 그 차이를 통해 드리프트 발생 여부를 판별한다. 독립동일분포(i.i.d.) 귀무가설 하에서 통계적 검정이나 수학적 부등식을 적용해 유의미한 차이 수준을 결정한다. Adaptive Windowing (ADWIN), Hoeffding Drift Detection Methods ($HDDM_{A-test}$와 $HDDM_{W-test}$)가 대표적인 예다.

기존 윈도우 기반 기법들은 강력한 통계적 근거를 제공하지만 가변 크기 관리나 다중 서브 윈도우 유지로 인해 메모리와 연산 오버헤드가 발생한다.

## 3. Fast Hoeffding Drift Detection Method

FHDDM은 호에프딩 부등식(Hoeffding's inequality)의 엄밀한 오차 한계를 활용하여 스트림 데이터의 분포 변화를 $O(1)$ 복잡도로 감지한다.

FHDDM은 모델의 분류 결과 시퀀스에 크기 $n$의 고정 슬라이딩 윈도우를 적용한다. 예측이 맞으면 1(True)을, 틀리면 0(False)을 윈도우에 순차적으로 삽입한다. 데이터 스트림이 유입됨에 따라 시점 $t$에서 슬라이딩 윈도우 내 정답(1)이 관찰될 확률 $p_t^1$을 계산하고, 지금까지 스트림 전체에서 관찰된 최대 확률 $p_{max}^1$를 단일 레지스터로 유지한다.

- **$p_t^1$**: 시점 $t$ 기준 가장 최근 $n$개 인스턴스에서 올바른 분류 예측이 발생한 확률
- **최댓값 갱신**: $p_t^1$이 기존 $p_{max}^1$보다 크면 해당 값을 새로운 최댓값으로 업데이트한다 ($if\ p_{max}^1 < p_t^1 \Rightarrow p_t^1 \rightarrow p_{max}^1$).
- **드리프트 판정 조건**: 최댓값과 현재 확률의 차이가 호에프딩 임계치 $\epsilon_d$ 이상으로 벌어지면 드리프트 경보를 발생시킨다.
  - $\nabla p = p_{max}^1 - p_t^1 \ge \epsilon_d \Rightarrow Drift := True$
  - $\epsilon_d = \sqrt{\frac{1}{2n}\ln{\frac{1}{\delta}}}$

![image](https://user-images.githubusercontent.com/78655692/172021181-5a3ca703-981d-4aaa-959d-77782f4f56b4.png)

윈도우 크기 $n=10$, 신뢰도 파라미터 $\delta=0.2$로 설정하면 호에프딩 부등식에 따라 임계치 $\epsilon_d = \sqrt{\frac{1}{2 \times 10}\ln{\frac{1}{0.2}}} \approx 0.28$이 산출된다.

위 그림의 예시에서는 실제 드리프트(real drift)가 12번째 인스턴스 직후에 발생했다.

- **초기 상태**: 윈도우 진입 초기에는 $p_{max}^1$가 0으로 초기화된 상태에서 점차 갱신되며, 10번째 인스턴스 시점에서 윈도우 내 정확도 $p_{10}^1$는 0.7을 기록하고 $p_{max}^1$ 역시 0.7로 설정된다.
- **성능 저하 관측**: 11번째 인스턴스부터 정답률이 떨어지기 시작하여 윈도우 내 0의 비율이 증가한다.
- **경보 발생**: 18번째 인스턴스 시점에서 $p_{18}^1$이 0.4로 하락하면서 $p_{max}^1$과의 차이가 $\Delta p = 0.7 - 0.4 = 0.3$이 된다. 이 차이가 임계치 $\epsilon_d$를 초과하므로($0.3 > 0.28$), FHDDM 알고리즘은 즉시 드리프트 경보를 발생시킨다.

단일 윈도우 통계량과 고정 임계치 비교만으로 지연 없이 변화를 포착한다.

### Window-based Approaches 비교

FHDDM은 기존 윈도우 기반 기법들이 안고 있던 메모리 복잡도 문제를 구조적으로 해결한다.

기존의 윈도우 기반 접근법들은 분포 비교를 위해 통상 두 개의 하위 윈도우($w_1$과 $w_2$)를 분할 유지하므로 상당한 메모리 사용량과 관리 오버헤드를 유발한다. 첫 번째 윈도우는 시작 시점부터의 장기 과거 정보(historical information)를 보관하고, 두 번째 윈도우는 가장 최근 데이터를 추적하는 식이다.

반면 FHDDM은 현재 분류기의 성능을 과거 최적의 성능과 비교할 때 오직 하나의 고정 슬라이딩 윈도우(크기 $n$)만을 활용한다. 따라서 메모리 상에는 최댓값을 저장하는 단 하나의 레지스터 $p_{max}^1$와 크기 $n$의 단일 슬라이딩 윈도우 버퍼만 차지하여 자원 소비를 극소화한다.

### Pseudocode of FHDDM

FHDDM 알고리즘의 동작 절차를 나타낸 의사코드(Pseudocode)는 다음과 같다.
```javascript
// Alogirhtm 1.
function INITIALIZE(windowSize, delta)
    n=windowSize
    δ=delta
    εd=sqrt(1/2n ln(1/δ))
    RESET()
end function
function RESET()
    w=[] // Creating an empty sliding window.
    p1_max=0
end function
function DETECT(p) // p is 1 for the correct predictions, 0 otherwise
    if w.size()=n then
        w.tail.drop() // Dropping an element from the tail
    end if
    w.push(p) // Pushing an element into the head.
    if w.size()<n then
        return False
    else
        p1=w.count(1)/w.size() // The recent probability of seeing 1s.
        if p1_max<p1 then
            p1_max=p1
        end if
        Δp=p1_max-p1
        if Δp ≥ εd then
            RESET() // Resetting parameters.
            return True // Signalling for an alarm.
        else
            return False
        end if
    end if
end function
```


## 4. On Evaluation of Concept Drift Detectors

스트림 환경에서 컨셉 드리프트 감지기의 실질적인 성능을 측정하려면 전통적인 지연 시간 외에 분류 메트릭 체계를 정밀하게 수립해야 한다.

드리프트 감지기는 높은 TP(True Positive)를 보이면서도 FP(False Positive)와 FN(False Negative)은 최소화해야 이상적이다. 예를 들어 합성 벤치마크에서는 베르누이 분포로부터 비트 스트림을 생성하여 변화를 주입하고, 감지기가 알람을 울릴 때마다 허용 구간 내외 여부를 판정해 오탐과 정탐을 집계한다.

본 논문에서는 허용 지연 길이 $\Delta$를 기준으로 정의하여 TP, FP, FN을 정량화하는 엄밀한 평가 프레임워크를 제안한다.

- **허용 지연 길이 ($\Delta$)**: 검출된 드리프트 시점이 실제 드리프트 발생 위치로부터 얼만큼 떨어져 있는지를 평가하기 위해 설정된 허용 임계값이다.

![image](https://user-images.githubusercontent.com/78655692/172064654-727af929-ebc0-4862-bac4-adc09368c2b5.png)

- **True Positive (TP)**: 실제 드리프트가 발생한 시점 $t$를 기준으로 허용 구간 $[t-\Delta, t+\Delta]$ 내에 감지기가 경보(alarm)를 발생시킨 경우다.
  - 이 구간을 TP의 허용 감지 구간(acceptable detection interval)이라 부른다.
  - 스트림 내 전체 드리프트 발생 건수 중 정상 식별된 드리프트 비율로 TP 비율을 정의한다.
  - 지연 반응성만을 엄격히 평가하는 반응형(reactive) 검정에서는 허용 간격을 $[t, t+\Delta]$로 제한한다.
- **False Positive (FP)**: 감지기가 허용 감지 구간 밖에서 잘못된 드리프트 경보를 발생시킨 경우(오경보)를 의미한다.
  - FP 비율은 실제 드리프트가 발생하지 않은 구간에서 발생한 오탐 빈도로 정의된다.
- **False Negative (FN)**: 실제 드리프트 시점 $t$를 중심으로 한 허용 구간 $[t-\Delta, t+\Delta]$ 내에서 감지기가 끝내 경보를 울리지 못한 경우(미탐)다.
  - FN 비율은 전체 드리프트 발생 건수 중 감지하지 못하고 누락된 비율로 정의된다.
  - 반응형 검정 시 허용 간격은 동일하게 $[t, t+\Delta]$를 적용한다.

정밀한 평가 구간 설정을 통해 알고리즘의 조기 탐지 능력과 안정성을 객관적으로 입증할 수 있다.

## 5. Experimental Analysis

다양한 합성 데이터셋과 분류기를 결합하여 기존 대표 탐지 기법들과의 성능 비교 실험을 수행한다.

실험에서는 데이터 스트림 분류기로 널리 사용되는 VFDT(Very Fast Decision Tree) 기반 Hoeffding Tree (HT)와 Naive Bayes (NB)를 평가 모델로 선정했다. 또한 급격한 변화와 점진적 변화를 모두 아우르기 위해 3가지 합성(synthetic) 데이터셋을 구축하고 실제 환경을 모사하기 위해 10%의 노이즈를 주입했다.

- **SINE1**: 급격한 드리프트(abrupt concept drift) 시나리오
- **MIXED**: 급격한 드리프트(abrupt concept drift) 시나리오
- **CIRCLES**: 점진적 드리프트(gradual concept drift) 시나리오

## 6. 핵심 요약 및 시사점

FHDDM은 엄밀한 통계 이론과 극단적인 경량 아키텍처를 결합하여 고속 데이터 스트림에 최적화된 컨셉 드리프트 감지 솔루션이다.

- **단일 윈도우 기반 경량화**: 다중 서브 윈도우를 유지하는 기존 기법과 달리, 크기 $n$의 단일 슬라이딩 윈도우와 최댓값 레지스터 $p_{max}^1$ 하나만으로 동작하여 메모리 점유를 수백 바이트 수준으로 억제했다.
- **호에프딩 부등식의 엄밀한 바운드**: 기저 분포에 대한 파라메트릭 가정이 필요 없는 Hoeffding's inequality를 활용하여 $\epsilon_d$를 수학적으로 도출함으로써 신뢰성 있는 드리프트 판정을 보장했다.
- **낮은 지연 시간과 오탐 통제**: 복잡한 히스토그램 분할 연산 없이 $O(1)$ 시간 복잡도로 신속하게 경보를 울려, SOTA 대비 탐지 지연(delay)과 FP/FN 비율을 대폭 낮췄다.
- **평가 프레임워크 표준화**: 허용 지연 간격 $\Delta$를 기반으로 한 TP, FP, FN 정량 평가 방식을 정립하여 후속 스트림 마이닝 연구의 비교 기준을 제시했다.
