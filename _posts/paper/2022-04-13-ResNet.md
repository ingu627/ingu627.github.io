"Deep Residual Learning for Image Recognition" 논문을 공부하고 핵심 내용을 정리한 리뷰다.

- **논문 링크**: <https://arxiv.org/abs/1512.03385>
- **핵심 문제 (Core Bottleneck)**: 신경망의 깊이가 깊어질수록 기울기 소실(vanishing gradients)과 함께, 과적합이 아님에도 훈련 에러가 오히려 증가하는 망 분해/성능 저하(degradation) 문제가 발생한다.
- **핵심 해결책 (Key Insight)**: 레이어가 기본 매핑 $\mathcal{H}(x)$를 직접 학습하는 대신 잔차 매핑 $\mathcal{F}(x) := \mathcal{H}(x) - x$를 학습하도록 설계하고, 파라미터가 없는 identity 숏컷 연결(shortcut connection)로 $\mathcal{F}(x) + x$를 구성하여 극단적으로 깊은 네트워크도 손쉽게 최적화할 수 있도록 했다.

## 1. Introduction
심층 합성곱 신경망에서 네트워크 깊이는 모델의 표현력과 시각 인식 성능을 좌우하는 핵심 축이다. 하지만 깊이를 단순히 늘리는 것만으로는 최적화 한계에 부딪힌다.

네트워크의 깊이가 깊어질수록 ImageNet 분류 성능이 비약적으로 발전해 온 만큼, 모델 깊이는 시각 인식 성능을 좌우하는 결정적 요인으로 자리 잡았다. 자연스럽게 다음과 같은 근본적인 의문이 제기된다.

> Is learning better networks as easy as stacking more layers?

레이어를 단순히 깊게 쌓는 것만으로 더 뛰어난 네트워크를 얻을 수 있는가 하는 질문이다.

이 물음에 답하기 위해서는 먼저 전통적인 장애물인 **기울기 소실(vanishing gradients)** 문제를 해결해야 한다. 그러나 배치 정규화(Batch Normalization) 등으로 기울기 소실/폭주를 방지하여 깊은 망이 수렴(convergence)하기 시작하더라도, 또 다른 치명적인 **성능 저하(degradation)** 문제가 드러난다.

- **정확도 포화 및 급격한 저하**: 네트워크 깊이가 증가함에 따라 정확도가 포화(saturated)된 후 급격히 저하되는 현상이 발생한다.
- **과적합이 아닌 최적화의 한계**: 이러한 성능 저하는 과적합(overfitting) 때문이 아니며, 실제로 층을 더 쌓았을 때 훈련 에러(training error) 자체가 오히려 더 높아진다(Fig. 1).

<img src='https://user-images.githubusercontent.com/78655692/163181920-a1d5cb78-cefb-465a-b2f4-526ae84bfc44.png' width=450>

깊이가 깊어질수록 훈련 에러가 증가한다는 사실은 깊은 모델이 얕은 모델보다 최적화하기 훨씬 어렵다는 점을 시사한다.

본 논문에서는 이러한 성능 저하 문제를 해결하기 위해 **심층 잔차 학습 프레임워크(deep residual learning framework)**를 도입한다. 각 쌓인 층들이 목적 매핑을 직접 학습하도록 강제하는 대신, 잔차(residual) 매핑을 학습하도록 목표를 재정의한다.

- **$x$**: 레이어 블록의 입력(input)
- **$\mathcal{H}(x)$**: 레이어들이 궁극적으로 근사해야 하는 기본 매핑(underlying mapping)
- **$\mathcal{F}(x) := \mathcal{H}(x) - x$**: 쌓인 비선형 층들이 피팅하도록 학습시키는 잔차 매핑 (weight layer $\rightarrow$ ReLU $\rightarrow$ weight layer)
- **$\mathcal{F}(x) + x$**: 원래 목표했던 매핑을 항등 연결과 더해 복원한 최종 형태 (weight layer $\rightarrow$ ReLU $\rightarrow$ weight layer $\rightarrow$ add $x$ $\rightarrow$ ReLU)

예측하려는 목적 함수가 입력과 유사하다면, 미지의 $\mathcal{H}(x)$ 전체를 바닥부터 피팅하기보다 입력과의 차이인 잔차 $x - \mathcal{H}(x)$(혹은 $\mathcal{H}(x) - x$)를 학습하는 편이 수치적으로 훨씬 쉽고 빠르다. [^7]

<img src='https://user-images.githubusercontent.com/78655692/163184908-cd6aed01-94d8-458b-bc3a-2a40a9833f01.png' width=540>

이 잔차 수식 $\mathcal{F}(x) + x$는 **숏컷 연결(shortcut connection, skipping one)**을 갖춘 피드포워드(feedforward) 신경망 구조를 통해 물리적으로 구현된다.

- **피드포워드(feedforward)**: 입력 층(input layer)에 주입된 데이터가 1개 이상의 은닉 층(hidden layer)을 거쳐 출력 층(output layer)으로 순방향 전달되는 기본 구조다. [^5]
- **파라미터 없는 항등 매핑**: shortcut connection은 단순히 **항등(identity)** 매핑을 수행하며, 그 출력을 중간 합성곱 층들을 통과한 출력에 요소별로 더해준다(Fig. 2).
- **추가 연산량 제로**: 이 연결선은 추가 학습 파라미터나 계산 복잡도를 발생시키지 않는다.
- **정보 보존 및 직접 전달**: 특정 층들을 건너뛰어 신호를 상위 층에 직접 전달함으로써 역전파 시 기울기가 손실 없이 하위 층까지 안정적으로 흐르게 된다. [^6]

결국 잔차 매핑 하나로 수렴과 깊이 문제를 모두 풀었다.

본 연구가 실증적으로 증명하는 핵심 가치는 다음 두 가지로 요약된다.

1. **최적화 용이성**: 깊은 잔차 네트워크(deep residual net)는 층 수가 극단적으로 깊어져도 최적화가 용이하며, 깊어질수록 훈련 에러가 높아지던 기존 plain net의 문제를 완전히 해소한다.
2. **깊이에 따른 정확도 향상**: 대폭 늘어난 깊이(depth)로부터 실질적인 표현력 이득을 얻어 정확도가 크게 향상된다.
## 2. Related Work

잔차 표현과 숏컷 구조는 전통적 비전 알고리즘과 신경망 역사에서 다양한 형태로 시도되어 온 개념이다.

### Residual Representations

이미지 인식 분야의 고전적 특징 벡터 추출에서도 잔차를 이용한 인코딩이 뛰어난 성능을 입증한 바 있다.

- **VLAD**: 사전(dictionary)의 시각 단어와 관련하여 잔차 벡터(residual vector)로 인코딩하는 대표적 표현 기법이다.
- **Fisher Vector**: VLAD를 확률적(probabilistic) 프레임워크로 확장한 버전으로 잔차 정보를 효과적으로 활용한다.

### Shortcut Connections

네트워크 내에서 레이어를 건너뛰는 연결 방식은 이전에도 연구되었으나, 제어 방식에서 결정적인 차이가 존재한다.

- **Highway Network와의 차이**: 게이트 기반 숏컷(gated shortcut)을 사용하는 highway network는 게이트가 닫히면(approaching zero) 레이어가 비잔차(non-residual) 함수로 동작한다.
- **상시 열려 있는 ResNet의 Identity Shortcut**: ResNet의 identity shortcut은 매개변수가 없으며 결코 닫히지 않는다. 모든 신호와 기울기가 잔차 학습을 통과하며 상시 자유롭게 흐른다.

이처럼 항상 열려 있는 항등 연결이야말로 잔차 학습의 견고한 최적화를 보장하는 핵심 열쇠가 된다.
## 3. Deep Residual Learning

잔차 학습의 기본 철학과 수학적 formulation, 그리고 숏컷을 결합한 빌딩 블록의 구조적 세부사항을 살펴본다.

### 3.1 Residual Learning

다수의 비선형 층들이 점근적으로 복잡한 함수를 근사할 수 있다면, 잔차 함수 $\mathcal{H}(x) - x$ 역시 동일하게 근사할 수 있다는 가설에서 출발한다.

따라서 비선형 층들이 직접 $\mathcal{H}(x)$를 맞추기보다, 잔차 함수 $\mathcal{F}(x) := \mathcal{H}(x) - x$에 명시적으로 근접하도록 최적화 목표를 전환한다. 최종 출력 매핑은 항등 입력을 더한 $\mathcal{F}(x) + x$가 된다.

> 기존 신경망이 H(x) - x = 0을 만들려 했다면 ResNet은 H(x) - x = F(x) 로 두어 F(x)를 최소화 시키려고 합니다. 즉 F(x) = 0 이라는 목표를 두고 학습을 진행합니다. 이렇게 학습을 진행하면 F(x) = 0이라는 목표값이 주어지기 때문에 학습이 더 쉬워집니다. 결국 H(x) = F(x) + x 가 되는데 이때 입력값인 x를 사용하기 위해 쓰는 것이 Skip Connection입니다. 즉 Skip Connection은 입력 값이 일정 층들을 건너뛰어 출력에 더할 수 있게 하는 역할을 합니다. [^1]

**기존 구조와 잔차 구조의 비교**

![image](https://user-images.githubusercontent.com/78655692/163760970-434e57eb-e164-42bd-817f-0d2dac9e2a0b.png)

- **기존 Plain CNN 구조**: $x \rightarrow$ weight layer $\rightarrow$ ReLU $\rightarrow$ weight layer $\rightarrow$ ReLU $\rightarrow \mathcal{H}(x)$ 순으로 진행하며, 최적의 $\mathcal{H}(x)$를 얻기 위해 가중치를 전면 수정한다.
- **ResNet 잔차 구조**: 가중치 층들이 $\mathcal{F}(x)$를 학습하도록 하여, 목적 출력과 입력의 차이인 $\mathcal{H}(x) - x$를 0에 가깝게 최소화하도록 유도한다.

만약 항등 매핑이 최적이라면 가중치들을 단순히 0에 가깝게 수렴시키면 되므로 학습 난이도가 획기적으로 낮아지며, 입력 $x$의 미세한 변화(잔차)를 민감하게 포착할 수 있다. [^4]
### 3.2 Identity Mapping by Shortcuts

잔차 학습 단위는 identity shortcut connection을 포함하는 기본 빌딩 블록(building block)으로 구성된다.

![image](https://user-images.githubusercontent.com/78655692/163199522-52779629-e29f-4ce6-ae4b-e8b112c1000a.png)
이미지 출처: [^2]

기본 빌딩 블록의 수식은 입력과 출력의 차원 일치 여부에 따라 정의된다.

- **차원이 동일한 경우**:
  $$y = \mathcal{F}(x, \{W_i\}) + x$$
  여기서 $\mathcal{F}$와 $x$의 차원은 반드시 일치해야 하며, 숏컷 연결을 통한 요소별(element-wise) 덧셈이 수행된다. 활성화 함수 $\sigma$는 ReLU를 사용한다.
- **차원이 변경되는 경우**:
  $$y = \mathcal{F}(x, \{W_i\}) + W_s x$$
  스트라이드 적용이나 채널 수 증가로 $\mathcal{F}$와 $x$의 차원이 다를 때는 선형 투영(linear projection) 행렬 $W_s$ (또는 $W_i$)를 곱해 차원을 일치시킨 후 더해준다.
### 3.3 Network Architectures

VGGNet의 철학을 계승한 기본 plain 네트워크 위에 identity shortcut을 체계적으로 결합하여 ResNet 아키텍처를 완성한다.

![resnet](https://user-images.githubusercontent.com/78655692/163201846-aadaff8d-a5c7-4728-8a6c-04a1bcadf218.jpg)

네트워크는 주로 3x3 합성곱 필터를 사용하며, 동일한 출력 피처 맵 크기를 가질 때는 동일한 수의 필터를 유지하고 피처 맵 크기가 절반으로 줄어들 때 필터 수를 2배로 늘려 시간 복잡도를 일정하게 보존한다.

### 3.4 Implementation

안정적인 학습과 재현성을 보장하기 위해 규격화된 표준 하이퍼파라미터 및 학습 설정을 적용했다.

- **데이터셋**: ImageNet 2012 classification dataset
- **입력 크기**: 224 x 224 무작위 크롭 및 증강
- **정규화**: 각 합성곱(conv)과 활성화 함수 사이에 배치 정규화(Batch Normalization, BN) 적용
- **최적화 기법**: 미니 배치 크기 256의 SGD(Stochastic Gradient Descent)
- **학습률 (Learning Rate)**: 0.1에서 시작하여 에러가 정체될 때마다 10으로 나눔
- **반복 학습 횟수**: 모델은 최대 $60 \times 10^4$ iterations까지 훈련
- **가중치 감쇠 (Weight Decay)**: 0.0001
- **모멘텀 (Momentum)**: 0.9
- **드롭아웃 (Dropout)**: 미사용 (BN이 정규화 역할을 대신함)
## 4. Experiments

ImageNet 벤치마크 실험을 통해 plain 네트워크와 ResNet의 깊이별 성능을 비교 검증한다.

![image](https://user-images.githubusercontent.com/78655692/163204278-5d7dbb41-355f-42d3-8a93-8bcb28004a51.png)

실험 결과, plain net에서는 18층에서 34층으로 깊어질 때 훈련 에러가 오히려 상승하는 성능 저하가 뚜렷하게 관찰되었다. 반면 ResNet-34는 ResNet-18 대비 훈련 에러가 확실히 감소하고 검증 정확도가 향상되어 깊이에 따른 표현력 이득을 온전히 달성했다.

### Deeper Bottleneck Architectures

연산 비용과 훈련 시간을 현실적인 수준으로 통제하면서 50층 이상의 더 깊은 네트워크를 구축하기 위해, 기본 블록을 **병목(bottleneck)** 구조로 전환했다(Fig. 5).

- **1x1 합성곱을 통한 차원 축소 및 복원**: 1x1 conv로 채널 차원을 축소한 뒤 3x3 conv 연산을 수행하고, 다시 1x1 conv로 차원을 복원한다.
- **연산 효율성 극대화**: 연속된 두 개의 3x3 conv 층을 사용하는 기본 블록에 비해 파라미터 수와 계산량을 크게 절감할 수 있다.
- **초심층 망 확장**: 이 bottleneck 구조 덕분에 ResNet-50, ResNet-101, 나아가 152층(ResNet-152)에 이르는 초심층 네트워크를 성공적으로 구축할 수 있었다.

## 5. 핵심 요약 및 시사점

ResNet은 심층 신경망 최적화의 패러다임을 근본적으로 바꾼 기념비적인 연구다.

- **잔차 학습(Residual Learning) 도입**: 레이어가 목표 매핑 전체를 근사하는 대신 차이값인 $\mathcal{F}(x) := \mathcal{H}(x) - x$를 학습하도록 하여 최적화 난이도를 획기적으로 낮췄다.
- **파라미터 없는 Identity Shortcut**: 연산량 증가 없이 신호와 기울기를 망 전체로 직결 통과시켜 깊은 망의 기울기 소실 및 분해 문제를 해결했다.
- **성능 저하(Degradation) 극복**: 층을 쌓을수록 훈련 에러가 증가하던 문제를 해소하고, 152층까지 네트워크를 확장하여 ILSVRC 2015 1위 및 top-5 에러율 3.57%를 기록했다.
- **Bottleneck 구조를 통한 실용성 확보**: 1x1 합성곱 기반의 병목 블록으로 연산 복잡도를 억제하며 초심층 모델의 효율적 학습을 가능케 했다.

현대 딥러닝 비전 아키텍처의 표준 토대가 된 혁신적인 설계다.
