  - Microsoft Azure 엔터프라이즈 클라우드 아키텍처 설계 및 구축
  - Kubernetes (AKS), Azure Container Apps (ACA) 기반 마이크로서비스 오케스트레이션

  - LLM 애플리케이션 서빙 아키텍처 (RAG, Vector DB, LangGraph, MCP)

  - Apache Spark, Kafka 기반의 대용량 데이터 스트리밍 및 분산 처리
  - 분산 합의 알고리즘, 내결함성(Fault Tolerance), 일관성 모델
